    Description

    AnimCJK contains SVG files to draw Chinese Hanzi, Japanese Kana or Kanji and Korean Hanja stroke by stroke.

    The Chinese repository contains "Commonly used Hanzi" (7000 characters) and other characters ("Uncommon Hanzi", "Traditional Hanzi as in China", "Components", "Bopomofo" and "Strokes").

    The Japanese repository contains "Kana" (177 characters), "Jōyō Kanji" (2136 characters), "Jinmeyō Kanji" (863 characters) and other characters ("Hyōgai Kanji", "Components" and "Strokes").

    The Korean repository contains some "Hanja".

    The Taiwanese repository contains some of the 4808 traditional Hanzi used in Taiwan, other Hanzi and some components.

    Note that the Hanzi don't necessarily have the same glyph or stroke order in China and Taiwan even if they share the same unicode!

    Accessibility

    A click on a character animates it. The same can be done with the keyboard.

    Select and animate a character with the keyboard

    • Give focus to the list containing the character with the Tab or Shift + Tab keys
    • Move the selection within the list with the Arrow keys
    • Press the Enter key to animate the selected character

    Shortcuts

    • a: open this dialog
    • b: go back to the list of the selected character if there is one
    • p: go to the preferences panel
